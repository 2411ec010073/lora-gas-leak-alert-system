# lora-gas-leak-alert-system
ESP32-based emergency alert system that detects hazardous gas leakage using an MQ-2 sensor and transmits long-range wireless alerts via LoRa (SX1278/RA-02). Features local buzzer/LED/OLED warnings at the sensor node and a remote monitoring receiver that displays "GAS LEAKAGE DETECTED" — no Wi-Fi or internet required.
